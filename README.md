# Spring Boot Lab – Practical 03

This lab introduces the basics of the Spring Boot framework and RESTful web services.

## What I Implemented

- Created a Spring Boot application using Spring Initializr
- Implemented a root endpoint ("/") returning "Hello world!"
- Created a "/hello" endpoint
- Added query parameter support ("/hello?name=Amith")
- Implemented a "/greet" endpoint
- Added path variable support ("/greet/{name}")
- Added optional query parameter support ("/greet/{name}?message=...")

## Technologies Used

- Java 21
- Spring Boot
- Maven
- VS Code

This lab helped me understand:
- REST endpoints
- @GetMapping
- @RequestParam
- @PathVariable
- Basic Spring Boot project structure
